# 화면 조작과 연출

## 0 현재 구현 기준 · 2026-11-18

게임명은 **변경의 신임 영주가 되었다**다. 플레이 흐름은 **가문 강화 → 영주·영지·환경 조건·장비 준비 → 개발·작업반·성물 조합 → 한 주 진행과 결과 확인 → 겨울 평가 → 결산과 재분배**다. 직접 결정하는 것은 투자와 작업의 우선순위, 사건·특전·성물의 손익이다. 노동 인원을 일일이 입력하거나 같은 인물을 매주 다시 접견할 필요는 없다.

현재 메인은 **상단 수치·계절 목표 → 도트 영지 집무실 → 오른쪽 이번 주·공사·성장 탭**이다. 건설은 별도 **마을·농경지·작업장·성벽 4지구**에서 진행하며, 새 통치에서 판타지 협약을 채택하면 **이계 지구**가 추가된다. 이번 주 탭에서 작업반과 직전 결과, 공사 탭에서 투자와 공사 순서, 성장 탭에서 계절 목표·승격·환경 조건·협약 진행을 확인한다. 하단은 **집무실 / 영지 둘러보기 / 물자 / 통치·성장 / 1주 진행**으로 구성하며 포고·특전·보좌관·성물·기록은 통치·성장에서 연다. 주 진행 버튼은 하나다. 제목·가문 강화·출발 준비·회차 운영·결산은 서로 구분한다. 현재 실행 범위는 `godot/README.md`를 따른다. 마지막 절의 본편 확장 수량은 구현 완료 수량이 아니다.

## 1 제목 화면과 세 단계의 출발 준비

제목 화면은 새 도트 영주관 내부 위에 **새 영지에 부임 / 가문 강화 / 발견과 통치 기록 / 플레이 안내 / 종료**를 배치한다. 진행 중인 회차가 있으면 새 회차 시작 대신 **통치 이어 하기**를 보여 준다. 가문 강화 옆에는 보유 공훈을 표시한다. 가문 강화에 투자하지 않아도 출발할 수 있다.

| 준비 단계 | 선택 | 오른쪽에서 확인할 정보 |
|---|---|---|
| 1 영주 | 시드에서 생성한 후보 3명 중 1명 | 출신 효과, 장점 2개와 단점 1개 |
| 2 영지 | 숲·강변·고지대 중 1곳 | 지역 효과, 올해 겨울 시련, 이번 영지의 기회·제약 |
| 3 부임 물자 | 장비 6종에서 예산 안의 조합 | 선택 영주·지역, 첫 목표, 가문 특성과 방침·지원 물자 |

각 단계에서 이전·다음으로 이동하고 마지막 단계의 **통치 시작**으로 확정한다. **새 출발 조건 뽑기**는 준비 시드를 바꿔 후보·시련·환경 조건을 함께 갱신한다. 같은 시드에서 지역이나 장비를 바꾸는 것만으로 환경을 재추첨하지 않는다. 물자 예산은 기본 3이며 M20과 새 예산 강화가 각각 1씩 추가한다. 장비 예산과 가문 강화에 쓰는 공훈은 다른 자원이다.

출발 후 회차 첫 특전 하나를 선택한다. 장비는 시작 물자·초기 효과, 환경은 미리 공개한 회차 조건, 가문 특성은 회차 밖에서 유지하는 효과다. 특전은 이번 통치에서 모으며, 사건 성물은 별도로 획득해 세 칸 안에서 장착한다. 첫 개발은 농지 4→6구획 확대이며, 안내만 있는 첫 서신 EV01을 별도 팝업으로 반복하지 않는다.

기존 저장을 메뉴에서 읽기만 할 때는 수동 배치를 바꾸지 않는다. **통치 이어 하기**를 누르면 자원·시설·주차를 보존한 채 자동 노동과 보좌관을 사용하는 간편 통치로 전환한다. 미결 EV01 안내와 새 계약 제안은 정리하지만 이미 수락한 계약은 유지한다. 신규 캠페인의 생산 배율·20인 작업반 제한·시작 가문 특성·환경 조건·성물 규칙을 기존 진행 회차에 소급 적용하지 않는다. 확장 필드 없는 기존 회차는 4단계 부담·위기를 켜지 않고 기존 12성물·24특전 후보 풀을 유지한다. 작업반 규칙이 없는 저장은 기존 자동 노동을 유지한다.

## 2 가문 강화와 회차 성장

가문 강화는 **재정·농업·생존·건설·공업·외교 6계열, 각 8개로 48개 항목**이다. 기반 강화 24개, 선택권 해금 12개, 가문 방침 12개로 나눈다. 기존 단일 구매 강화 8개는 같은 화면의 **공통 강화**에서 계속 구매할 수 있어 전체 구매 항목은 56개다. 기존 구매 ID·가격·효과와 공훈 잔액은 보존한다.

화면은 계열 탭, 선택 계열의 실제 선행 연결선과 노드 경로, 고정 상세 영역으로 구성한다. 각 항목의 **종류·현재 단계·현재 효과·다음 효과·선행 조건·비용·적용 시점**을 구분하며 구매 버튼은 설명을 스크롤해도 보인다. 48개를 한 화면에 모두 늘어놓지 않는다. 시작 물자만 늘리는 항목과 새 선택을 여는 항목을 같은 것으로 표시하지 않는다.

| 종류 | 개수 | 구매 후 바뀌는 점 |
|---|---:|---|
| 기반 강화 | 24 | 시작 자원, 생산·유지·난방 등의 비용과 효율. 정의에 적힌 단계별 효과를 누적 |
| 선택권 해금 | 12 | 지원 물자 6종 중 1종 선택, 첫 특전·성물의 계열 지정, 추가 새로고침, 특전 후보 제외, 물자 예산 확대 |
| 가문 방침 | 12 | 해금한 방침에서 최대 2개 선택. 생산·재정·주민 관리의 장점과 대가를 함께 적용 |
| 공통 강화 | 8 | 기존 M계열 구매와 효과 유지. 물자 예산·특전 새로고침 등도 새 기능과 함께 계산 |

**공훈**은 통치 결산에서 얻어 가문 강화에 쓰는 영구 재화다. 구매는 **강화/해금**, 단계는 **1/3단계**, 재설정은 **무료 재분배**로 표시한다. 이번 통치의 특전, 성물 장착, 집무실 성장 탭과 가문 특성을 혼동하지 않게 이름과 적용 범위를 구별한다.

기반 강화는 보유한 효과가 적용되지만 방침과 지원 물자는 해금 후 직접 골라야 한다. 가문 방침은 최대 2개, 지원 물자는 최대 1묶음이며 선택하지 않고 시작해도 된다. 특전과 성물의 지정 계열은 첫 제안에만 적용한다. 새로고침·후보 제외는 회차별 사용 횟수가 있고 저장 후 재개해도 사용분이 복구되지 않는다. 원래 이용할 수 있던 기본 기능을 새 해금 뒤로 옮기지 않는다.

진행 중인 통치에서는 가문 특성 구매·환불·다음 통치 설정을 바꾸지 않는다. 회차 밖에서 **무료 재분배**하면 가문 특성에 실제 지불한 공훈을 돌려받고 그 특성에 의존하는 선택도 해제한다. 공통 강화 8개의 구매 내역과 발견 기록은 그대로다. 새 통치 시작 때 선택과 효과를 저장하므로 구매·환불·메뉴 재열기가 현재 통치의 자원이나 생산량을 바꾸지 않는다.

회차 내 특전은 **96종**이며 시작 및 6·13·20·26·33·39·46주 종료 후 선택한다. 기존 48개에 각 계열 12개씩 운영 방향을 나누는 복합 특전 48개를 더했다. 벌목 +30%/급여 +15%, 구매가 −18%/저장량 −10%처럼 이득과 부담을 함께 표시한다. 종자 효과는 2주, 파종 노동은 6주, 수확·징세는 36주 이후 신규 후보에서 제외하고 각 특전의 더 좁은 시기 조건도 적용한다. 농업·보존·생산·행정의 2개·4개 계열 효과와 성물 운영 조합은 유지한다.

### 2.1 출발 전에 공개하는 환경 조건

기회 3종과 제약 3종에서 시드별 하나씩, 총 두 조건을 정한다. 별도 난수 스트림을 써서 조건 조회가 영주 후보·특전·사건 추첨을 진행하지 않는다. 준비 화면의 이름·효과는 실제 저장한 효과와 같고, 운영 힌트는 보조 설명으로 제공한다. 성장 탭과 회차 결산에서도 같은 조건을 확인한다.

| 구분 | 조건 | 회차 효과 |
|---|---|---|
| 기회 | 야생 식량 풍부 | 채집 식량 +20% |
| 기회 | 오래된 산림 | 벌목 생산 +25% |
| 기회 | 상단 왕래 | 물자 상품 값 −15%, 운송료·판매가 제외 |
| 제약 | 메마른 밭 | 곡물 수확 −15% |
| 제약 | 긴 추위 | 겨울 장작 소모 +20%, 겨울 목표량에도 반영 |
| 제약 | 습한 창고 | 창고 안 식량 부패 +35%, 야적 손실은 유지 |

효과는 `state.expedition_modifiers`에 두 ID와 배율 스냅샷으로 저장한다. 기존 영주·지역·특전·가문 특성 효과를 덮어쓰지 않고 한 번씩 곱한다. 조회·준비 단계 왕복·저장 복원·규칙 갱신으로 재추첨하거나 중복 적용하지 않는다. 명시적인 새 회차 설정에서만 켜며 필드가 없는 기존 저장은 중립이다. 초기 농지의 공사 작업량은 변하지 않는다.

### 2.2 성물 획득·세 칸 장착·발견 도감

마을 성물은 **풍요·공방·수호 각 16종, 총 48종**이다. 확장 규칙 없는 진행 회차의 후보 풀은 각 4종인 기존 12종을 유지한다. 보유한 성물 중 **최대 3개**를 장착하며 장착한 효과만 적용한다. 같은 계열을 2개 이상 장착하면 조합 효과가 한 번 발생한다. 부임 물자와 별개이며 도감 발견 자체는 생산 보너스를 주지 않는다.

**운영 조합 12종**은 연결 성물 둘 중 하나를 장착하고 해당 계열 특전 2개를 갖추면 활성화한다. 기존 특전도 포함하며, 같은 조합의 성물 두 개를 장착해도 효과를 중복 적용하지 않는다. 곡물 수출·집약 채소 재배·곡물 비축·공동 식탁·목재 납품·대량 채석·조립식 건설·상단 조달·상비 경비대·집중 진료·겨울 난방망·책임 행정으로 생산과 자원 소비 방향을 나눈다.

성소의 **운영 조합**과 집무실 **성장**에서 조합 목록을 열고 필요한 성물·특전 수·효과·운영 부담을 확인한다. 성물 교체는 활성·해제될 조합을, 특전 후보는 연결되는 조합을 예고한다. 주간 교환은 실제 원장으로 조건을 확인하고 예약 공사 몫을 제외한 비용이 전부 있을 때만 한 번 적용한다. 같은 주 보상으로 다른 교환을 연쇄 지급하거나 재장착으로 보상을 다시 받지 않는다. 결산에는 실제 소비·보상과 마지막 활성 조합을 남긴다. 상세 수치는 Godot 빌드 안내의 운영 조합 표를 따른다.

| 계열 | 같은 계열 2개 장착 시 |
|---|---|
| 풍요 | 식량 저장량 +15% |
| 공방 | 시설 유지비 −15% |
| 수호 | 치안 목표 +3, 겨울 난방 소비 −8% |

확장 통치에서는 신규 성물을 하나 이상 포함해 같은 계열 3개를 장착하면 2개 조합에 전문화가 추가된다. **풍요는 수확 +20%/난방 +15%, 공방은 새 공사 작업량 −15%/급여 +20%, 수호는 치안 목표 +6/유지비 +20%**다. 세 칸을 한 계열에 쓸지 다른 성물을 섞을지 선택한다.

| 성물 | 실제 효과 또는 발동 조건 |
|---|---|
| 청동 낫 | 수확 +20%, 공공 작업 급여 +10% |
| 개척자의 바구니 | 채집 생산 +15% |

| 석공의 망치 | 새로 착공하는 공사의 필요 작업량 −15% |

| 빗물 주전자 | 급수 충족·채소 4 이상 생산한 주: 민심 +1. 시설 유지비 +10% |
| 목수의 먹줄 | 실제 공사 8인주 이상 처리한 주: 목재 4 → 석재 6. 목재 부족 시 미발동 |
| 대장장이의 풀무 | 대장간 도구 1 이상 생산한 주: 장작 6 → 도구 1. 장작 부족 시 미발동 |
| 상단의 저울 | 수입 물자가 실제 도착한 주: 금고 +0.6금 (주 1회) · 물자 구매가 +5% |
| 톱니 계산기 | 공사 없이 시설 유지비를 납부한 주: 금고 +0.6금. 새 공사 작업량 +10% |
| 순찰대의 등불 | 치안 55 이상·위협이 남은 주: 장작 3 → 위협 −3. 장작 부족 시 미발동 |
| 구휼소의 붕대 | 건강 60 미만·정상 배급 충족한 주: 공공 식량 8 → 건강 +2. 식량 부족 시 미발동 |
| 행군 북 | 치안 목표 +8 · 공공 작업 급여 +15% |
| 눈길 방울 | 겨울 난방을 충족한 주: 금고 0.4금 → 장작 8. 금고 부족 시 미발동 |

목재·장작·식량·금화를 쓰는 성물은 공사 예약 몫을 제외한 비용이 전부 있을 때만 비용과 보상을 함께 처리한다. 부족한 상태에서 무료 보상이나 음수 재고를 만들지 않는다.

성물 사건은 **4주 무너진 성소, 16주 성물 행상, 29주 봉인함, 42주 순례자**에 제안한다. 유적 복원·금화 구매·도구 교환·물자 제공 같은 비용과 당장 얻을 자원 사이에서 고른다. 모든 사건에는 비용 없는 대안이 있다. **첫 촌락 승격**, 확장 위기 「수확물을 노리는 도적」·「겨울 병동 과밀」 성공도 성물 후보를 제안한다. 보유하지 않은 후보 중 하나를 고르며 이미 처리한 발견 출처에서는 보상을 반복 지급하지 않는다.

획득 시 빈칸이 있으면 자동 장착하고 세 칸이 찼으면 보관함에 넣는다. 마을 지구 성소·통치·성장 메뉴·성장 탭에서 성소 화면으로 간다. 성소 화면은 장착 3칸, 활성 조합, 이번 회차 보관함, 선택 성물의 효과·해제·교체 행동을 보여 준다. 교체는 시간이나 추가 자원을 쓰지 않으며 이미 완공한 결과와 착공한 공사를 소급 변경하지 않는다.

제안 창은 성물 그림·계열·효과·현재 같은 계열 장착 수를 함께 보여 준다. **영지를 보고 결정**으로 접어도 후보는 남고 선택 전 주 진행을 막는다. 획득 확인은 이미 받은 성물을 알리는 단계이지 재지급 명령이 아니다. 주간 발동은 실제 완료한 주의 원장과 전후 상태를 사용하고 주마다 한 번만 처리한다. 상태 상한으로 실제 변한 값만 결산에 남긴다.

**발견 도감**은 회차 밖 `profile.relic_discoveries`에 남는다. 발견한 성물은 이름·효과를 볼 수 있고 미발견은 가린다. 다음 회차에서는 성물을 다시 획득해야 하며 보관함·장착은 이어받지 않는다. 현재 회차의 제안·보유·장착·발동 기록은 `state.realm.sanctuary`에 저장하고 새 규칙이 없는 구저장에는 성소를 생성하지 않는다.

### 2.3 짧은 투자 사건과 후속 결과

현재 사건은 **196개**다. 기본 15개·영지 34개·성물 4개·기존 확장 33개·긍정 40개·부정 40개에 판타지 협약 30개를 더했으며 후속 노드를 포함한다. 긍정·부정 80개는 무작위 시작 64개와 선택 전용 후속 16개다. 기존 확장 33개는 무작위 시작 17개와 후속 16개다. 협약 30개는 발견·시설 완공에 맞춰 예약하며 일반 사건 풀에 섞지 않는다. 목재 납품은 현금·도구 계약으로 나뉘고, 수습생 교육은 정비·건축으로 갈린다. 계약 비용은 선택 즉시 지불하고 예고한 주에 후속에서 보상을 고른다. 후속은 독립 추첨하지 않는다.

추가 사건은 계절·주차·완공 시설에 맞춰 한 회차에 한 번씩 등장한다. 긍정 사건은 즉시 보상과 발전 기회를, 부정 사건은 피해 방지·복구·손실 감수 중 선택을 제공한다. 비용·조건·확률이 없는 확정 대안을 반드시 둬 금고가 비어도 진행할 수 있다. 건물·포고·상태 외에 풍요·공방·수호 성물의 **장착 여부**로 열리는 대응도 있다. 보관함에 소유한 것만으로는 열리지 않는다.

사건 팝업 상단의 **좋은 소식 / 문제 발생**으로 상황을 구별하고, 선택지에서 지불·효과·성공률·실패 피해를 확인한다. 후속이 있는 선택은 도착 예정 주와 사건 이름을 미리 보여 주며 결과 창에도 남긴다. 종류 확장으로 기존 사건의 발생 빈도나 팝업 수를 늘리지 않는다. 확장 규칙이 없는 이전 저장에는 추가 사건을 추첨하지 않는다.

신규 사건 본문은 최대 63자, 선택은 2~3개다. 비용·즉시 효과·확률·후속 시점을 분리해 표시하며 모든 사건에 조건 없는 무료 대안이 있다. 시설을 보유하면 검수·감면 같은 유리한 대응이 열린다. 시작 사건은 회차당 한 번만 발생하고 후속 선택도 중복 보상을 지급하지 않는다. 저장 복원은 선택한 분기와 도착 주를 유지한다.

## 3 52주 캠페인과 계절의 대가

신규 회차는 13주씩 네 계절을 거친다. 변경 환경의 기본 수확·채집 배율은 현재 **55%**다. `content/campaign.json`의 이 값은 다른 생산 효과와 곱해지며, 기존 진행 회차의 생산을 바꾸지 않는다. 설정 수치와 실제 난이도 검증 결과는 구분한다.

| 기한 | 현재 상태로 판정할 목표 | 즉시 자동 보상 | 결산용 공훈 | 미달 비용 |
|---|---|---|---:|---|
| 봄 13주 종료 | 농지 6구획 | 목재 +16, 도구 +2 | +3 | 민심 −4, 금고 −3금 |
| 여름 26주 종료 | 곡물 곳간 1개 | 금고 +5금, 도구 +2 | +3 | 민심 −5, 금고 −5금 |
| 가을 39주 종료 | 겨울 13주분 장작 | 식량 +80, 금고 +3금 | +4 | 민심 −6, 금고 −5금 |
| 겨울 52주 종료 | 기본 목표 3개와 겨울 시련 | 금고 +8금 | +6 | 민심 −8 |

기한 주의 경제 처리와 회차 효과를 반영한 뒤 평가한다. 성공 보상은 별도 수령 버튼 없이 한 번 지급한다. 실패 비용은 실제 남은 금고와 0~100 범위의 민심에서 차감한다. 계절 실패가 곧바로 게임 종료는 아니며 다음 계절에 줄어든 여력으로 이어진다. 평가 결과는 계절 팝업과 기록에 남긴다. 팝업을 닫는 것은 다음 계절로 돌아가는 조작이지 보상 수령 명령이 아니다.

장작 목표는 `올림(현재 주민 수 × 0.1 × 13 × 난방 배율)`이다. 영지 규칙에서는 가을부터 성장 탭에 공개하는 겨울 날씨 예보와 예정된 한파 시련을 목표에 미리 반영한다. 39주 평가 뒤 처음 공개된 날씨 때문에 기준이 갑자기 높아지지 않도록 한다. 주민 수와 선택한 난방 효과에 따른 목표 변화는 계속 반영한다. 여름의 곳간 목표와 가을의 장작 목표는 일찍 준비해도 기한까지 유지해야 한다. 한 해의 성공은 **농지 6구획·곡물 곳간 1개·정상 배급 기준 식량 13주분·해당 겨울 시련 통과**로 평가한다. 배급 축소로 최종 식량 목표를 낮출 수 없다.

공훈은 회차 안에서 계절 목표 점수로 누적하고 결산 때 프로필에 지급한다. 13주를 완료한 회차부터 기본 목표·계절 생존·시련·과업·완주·첫 기록 보상을 계산한다. 13주 미만 종료에는 공훈을 지급하지 않고 첫 기록 보너스도 소모하지 않는다. 결산 화면은 합계와 계절 목표 추가 점수, 각 계절 결과를 함께 보여 준다. 같은 회차 결산을 반복해 점수를 더 받지 못하게 한다.

### 3.1 위기 예고와 운영 부담

확장 통치는 **위기 12종 중 회차마다 4개**를 겪는다. 8·18·30·42주에 각각 하나를 예고하고 12·24·36·48주 작업 후 평가한다. 각 구간의 3종 중 하나를 시드로 정한다. 요구량은 예고 때 인구·난방 배율 등을 반영해 고정하며, 집무실 제목 옆 **부담 N/4**와 **위기** 버튼(`OpenCrisis`)에서 요구량·현재 값·마감·보상·피해·대비 경로를 확인한다. 준비 버튼은 건설·보급·포고 등 해당 업무로 연결한다.

| 적용 시작 | 물자값 | 공공 급여 | 유지비 | 위협 증가량 |
|---|---:|---:|---:|---:|
| 1주 정착 유예 | 추가 없음 | 추가 없음 | 추가 없음 | 추가 없음 |
| 14주 수요 증가 | +5% | +6% | +5% | +10% |
| 27주 공급 압박 | +10% | +12% | +12% | +25% |
| 40주 겨울 고비 | +16% | +18% | +20% | +40% |

해당 단계의 배율을 한 번 적용하며 앞 단계나 매주 배율을 누적하지 않는다. 물자값은 상품 가격만 바꾸고 고정 운송료에는 적용하지 않는다. 다음 상승은 3주 전 소식으로 예고한다. 기한 주 결과에 따라 보상 또는 피해를 한 번 반영하고 주간 결산·회차 결산에 성공 여부를 남긴다. 미달만으로 즉시 회차를 끝내지는 않는다. 이미 반영한 판정을 다시 열거나 저장을 복원해도 반복 지급하지 않는다.

새 회차의 `config.escalation:true`와 `state.escalation.enabled`가 위기·단계 부담·신규 사건/특전/성물·3개 성물 전문화의 적용 경계다. 기존 진행 회차의 경제와 획득 후보를 몰래 확장하지 않는다.

### 계절 지원과 개척 난도

7·20·33·46주에 집무실의 계절 지원 버튼이 열린다. 전용 화면에서 3개 제안의 결과 그림·효과·즉시 비용·적용 종료 주를 비교하고 하나를 구매한다. 미선택 상태에서도 주를 진행하며 계절이 지나면 제안이 만료된다. 추수 지원은 마지막 수확 주인 36주까지만 적용한다.

부임 준비에서는 개척 난도 0~5의 누적 규칙과 추가 공훈을 비교한다. 잠긴 단계도 내용을 읽을 수 있지만 선택은 해금된 단계만 가능하다. 기본 난도에서 52주 목표와 겨울 시련을 달성하면 1단계가 열리며, 이후 해당 단계를 성공 완주하면 다음 단계가 열린다. 결산은 이번 보상과 다음 해금 목표를 따로 보여 준다.

### 판타지 협약의 발견·분기·완공

새 통치의 **영지의 변화**는 정령숲·화룡·달빛 수로·태엽 골렘·황혼·별의 학당 여섯 계열을 다룬다. 8·14·20주부터 시드로 정한 세 계열을 발견하고 사건에서 최대 두 계열을 채택한다. 각 계열의 세 전용 건물은 실제 착공·완공을 거쳐 다음 사건을 연다. 전용 사건은 계열당 5개, 총 30개다.

성장 탭의 **발견과 전용 건물 확인** 또는 **통치·성장 → 영지의 변화**로 상세를 연다. 왼쪽은 여섯 계열의 미발견·발견·완공 상태, 오른쪽은 성장 방향과 운영상 대가, 전용 건물 세 단계다. 선택한 건물의 실제 효과와 현재 선택한 운영 분기를 구분하고, 비용과 **현장 확인** 버튼을 설명 스크롤 밖에 고정한다. 설명을 읽는 것만으로 비용·효과·난수를 변경하지 않는다.

첫 건물 완공 뒤 두 운영 분기 중 하나를 선택한다. 둘째 건물 완공 뒤 사고에 대응하고, 2주 뒤 최종 공사 허가를 검토한다. 사고에는 비용을 내는 확정 대응·확률 대응·피해를 받는 무료 확정 대응이 있으며, 최종 공사는 보류할 수 있다. 허가만으로 건물을 지급하지 않는다. 48주 허가 마감, 별도 공사비·자재, 현재 인력에 따른 완공 예상은 실제 건설 현장에서 확인한다.

채택하면 지구 탭에 **이계 지구**가 나타나며 계열당 세 시설, 최대 여섯 시설을 배치한다. 계열 배경 6종과 전용 건물 그림 18종은 실제 선택·완공 상태에 연결한다. 셋째 건물을 완공하면 성물 제안 또는 계열별 물자 중 보상을 고른다. 52주 진입 이후 완공은 물자로 자동 정산해 결산 뒤 미결 보상 창이 남지 않게 한다. 결산은 채택한 계열, 운영 분기와 실제 완공 개수를 표시한다.

기존 저장에 `state.fantasy`가 없으면 새 협약을 소급 적용하지 않는다. 발견 계획·거절·채택·분기·공사·완성 기록은 저장 후 재개해도 유지한다. `FantasyFrontierDetail`, `FantasyBenefit`, `FantasyTradeoff`, `FantasyBuildingSteps`, `FantasyConstructionCost`, `FantasyGoSite`가 새 상세의 주요 검증 대상이다.

## 4 운영 화면의 정보 순서

기준 화면은 1440×900, 최소 크기는 1280×720이다. 현재 상태, 준비할 일, 선택, 처리 결과를 다음 순서로 배치한다.

| 영역 | 내용 | 역할 |
|---|---|---|
| 상단 상태 | 계절·회차·주차, 금고, 식량 비축 주수, 주민, 장작, 민심·건강·치안 | 현재 여력과 주민 상태 확인 |
| 계절 목표 띠 | 현재 과업, 달성 수치, 남은 주수, 가까운 파종·수확·평가 일정 | 다음 기한을 한 줄로 확인. 보상·미달 비용은 보조 설명과 목표 상세에 표시 |
| 집무실 장면 | 운영 소식·실제 결과 장부·담당 보좌관, 부담·위기·계절 지원 | 이번 주 결정과 결과를 구분 |
| 별도 건설 지구 | 기본 4지구·채택 후 이계 지구·독립 시설·임시 시설·공사장·전체 터 보기 | 동일한 지면 위에서 건설 상태 확인 |
| 이번 주 탭 | 운영 소식, 균형·먹거리·건설·장작, 예상 재고 변화·공사량, 직전 결과 | 이번 주 준비와 직전 선택의 결과를 같은 탭에서 비교 |
| 공사 탭 | 추천 개발, 시설별 이번 주 작업·예상 완공, 먼저·취소 버튼 | 어떤 시설을 먼저 완공할지 결정 |
| 성장 탭 | 계절 목표·보상·미달 비용, 승격 조건, 겨울 예보, 환경 조건·성물 조합 연결 | 다음 성장과 생존 기한 확인 |
| 하단 명령 | 집무실 / 영지 둘러보기 / 물자 / 통치·성장 / 1주 진행 | 필요한 업무를 열거나 현재 계획 실행 |

**물자**는 보급 주문, **통치·성장**은 포고·보좌관·특전·성물·기록을 여는 메뉴다. 운영 후에는 집무실로 돌아온다. **영지 둘러보기**에서는 현재 지구의 건물과 빈터만 표시하며, **전체 터 보기**로 미해금 시설을 확인한다. 건물은 최대 여섯 칸에 지면과 시점을 맞춰 놓는다. 마을의 성소는 장착 수만큼 등불을 켜며 클릭하면 성물 화면을 연다.

**1주 진행**은 화면에 하나만 둔다. 공사 탭은 승인·순서 변경·취소를 담당하고 시간 진행 버튼을 복제하지 않는다. 사업 승인과 방침·성물 장착 선택은 아직 시간이 흐르지 않는 준비이며, 하단 진행을 누를 때 착공 비용·생산·소비·공사·성물 조건부 발동이 처리된다. 미결 사건·특전·성물 제안이 있으면 같은 버튼이 결정 확인으로 바뀐다.

개발 영역은 승인 전 공사비·자재·예상 기간, 승인 후 착공 대기·남은 작업·진행률, 완공 후 시설 증가를 보여 준다. 착공 불가 사유는 행동 옆에 표시한다. 현재 과업·진행률·기한은 `CampaignDirector.overview`의 실제 판정 데이터에서 읽는다. 캠페인이 없는 구저장은 존재하지 않는 계절 평가 대신 52주 최종 평가까지의 시간을 보여 준다.

이번 주 탭의 `WeekResult`는 `state.last_receipt`의 실제 완료 결과다. 첫 진행 전에는 농지 개발로 이동하는 버튼을 보여 준다. 결과가 생기면 금고·식량 순변화와 주요 완공·승격을 요약하고 **결산 보기**를 제공한다. 기존 저장에 결과 스냅숏이 없으면 값을 만들어 내지 않는다.

**결산 보기**(`TurnDetails`)에서는 자원 변화의 원인, 완공·새 해금·승격과 주간 소식을 확인한다. 금고는 공공 현금이고 식량은 공공·주민 합계다. 방침 비교는 선택 전의 경제 예상이고 직전 결과는 입고·계절 효과 등을 처리한 실제 순변화다. 두 값의 범위를 구별하고 세부 내역에서 차이의 원인을 확인한다.

결과는 처리 직전 이후 새로 추가된 원장 항목을 사용한다. 미리 실행한 구매를 다시 지출로 세지 않고 다음 주 번호로 기록된 수레 도착·시련도 실제 처리 구간에 포함한다. 공공↔주민 식량 이전은 생산이 아니다. 착공 때 금고에서 지불한 전체 비용과 이후 예치금에서 인식하는 공사비를 구분한다. 원장에 근거 없는 자재 변화는 미분류 차이로 남기며 임의로 생산·소비라고 이름 붙이지 않는다. 보좌관 효과도 주말 건강·민심 전체 변화와 구별한다.

방침 비교와 완료 주수는 원본을 복제해 실제 경제 엔진으로 계산한다. 현재 예약·재고·배치는 반영하지만 미결 선택·새 사건·도착 물자·계절 보상과 벌칙·시련·민심과 건강 결산을 포함한 전체 미래 결과는 아니다. 화면 열기와 비교만으로 재고·난수·저장·보상을 변경하지 않는다.

## 5 개발과 직영 작업반

개발은 별도 건설 지구에서 시설 터를 고른다. 상세 설명만 스크롤하며 비용·예상 완공·승인 버튼은 고정한다. 공사 탭은 현 상태에 맞는 다음 개발을 제안한다. 처음 농지 4구획에서는 한 번의 승인으로 2구획을 함께 예약한다. 두 구획 모두 살 수 없으면 부분 예약하지 않는다. 영지 규칙은 예약·진행 공사를 합쳐 최대 3곳을 허용하며, 다른 시설은 사업당 1개다. 이전 규칙의 동시 공사 한도는 보존한다. 실제 자원 차감은 한 주 진행 때 처리한다. M04의 첫 농지 작업량 할인은 한 번만 적용한다.

공사 탭은 실제 처리 순서대로 시설을 나열하고 각 행에 **이번 주 작업량·예상 완공·진행률**을 표시한다. **먼저**는 해당 공사를 앞에 놓아 필요한 시설의 개장을 앞당긴다. 진행 중인 공사는 진행 중인 공사끼리, 예약은 예약끼리 바꾸며 예약이 이미 착공한 현장을 앞지르지는 않는다. 변경은 추가 비용·시간을 쓰지 않고 남은 작업·예치금·다른 공사의 순서를 보존한다. 검증에 실패하면 순서와 배치 모두 원래대로 유지한다. 취소는 실제 남은 예치금과 공사 진행률에 따른 자재를 반환한다.

공사 예상은 상태를 복제한 뒤 실제 착공·자동 배치·주간 경제 엔진으로 계산한다. 같은 시설 여러 개, 파종·수확 노동, 임금 체불 효율을 반영하며 원본 자원·난수·예약을 바꾸지 않는다. 미래 사건·보좌관·날씨 변화·물자 입고는 제외한 예상이다. 회차 종료까지 못 끝내거나 16주 이내 계산으로 해결되지 않으면 완공 날짜를 꾸며내지 않는다. 완공한 시설은 다음 주부터 가동한다.

신규 출발의 작업반 규칙은 명시적인 `campaign:true`와 `workcrew:true`로 시작한다. 농사 노동을 먼저 확보하고 **남은 가용 노동에서 최대 20명**을 직영 작업반에 배정한다. 한도가 남더라도 없는 시설이나 원료 없는 작업에 인원을 보내지 않는다. 작업반 이외의 가용 인원은 주민 생업으로 구분하고 배정하지 못한 작업반 인원은 유휴로 표시한다. 이전 회차에는 이 한도를 추가하지 않는다.

| 방침 | 채집 상한 | 공사 상한 | 나머지 우선순위와 대가 |
|---|---:|---:|---|
| 균형 | 채집터당 4명 | 8명 | 공사·채집·목재·다른 생산으로 나눔 |
| 먹거리 | 채집터당 8명 | 4명 | 채집·채소를 먼저 확보하므로 공사가 늦어짐 |
| 건설 | 채집터당 2명 | 16명 | 직영 인력을 공사에 먼저 배정 |
| 장작 | 채집터당 4명 | 4명 | 벌목소 인원을 장작 가공에 먼저 쓰며 실제 목재를 소비 |

각 상한을 전부 동시에 배정하는 것은 아니다. 합계는 해당 주의 직영 인원 한도를 넘지 않으며 실제 투입량은 시설 수·자재·농번기·남은 작업에 따라 달라진다. 벌목과 장작 가공은 같은 작업장의 인원 한도를 공유한다. 목재가 부족하면 일부 인원을 벌목에 먼저 배치해 같은 주 장작 가공에 공급한다. 겨울에 생산하지 못하는 일반 채집·채소 작업에는 사람을 보내지 않는다. 생산 배율이나 무료 자원을 방침 보상으로 추가하지 않는다.

비교 버튼의 **한 주 뒤 변화 · 공사 예상**은 **식량 재고 순변화·공사 작업량·목재 재고 순변화·장작 재고 순변화**를 같은 순서로 보여 준다. 생산과 소비·보관 손실·파종 종자·착공 자재를 모두 반영한 경제 예상이다. 보좌관·사건·입고·계절 보상과 벌칙·겨울 시련·주민 상태 결산은 제외하며 이 범위를 보조 설명에 표시한다. 선택할 수 없으면 벌목소 필요·진행 공사 없음 등 이유를 표시한다. 선택은 다음 주 진행 때 적용하며 바꾸기 전까지 유지한다. 처음에는 균형으로 시작한다. 선택한 방침이 완공·계절 변화로 유효한 작업을 잃어도 시간 진행 자체를 막지는 않는다.

기본 농지 두 구획은 균형의 건설 8명으로 2주, 건설 집중의 16명으로 1주에 완공할 수 있다. 먹거리 집중은 건설 4명으로 처리해 두 번째 농지가 첫 파종보다 늦어질 수 있다. 실제 조작 안내의 첫 개발은 균형을 유지해 3주 파종 전에 6구획을 완성한다. 이미 경과한 주나 자재·미결 결정에 따라 같은 완료 날짜를 보장하지 않는다.

영지 규칙에서는 작업반을 배정한 뒤 남는 주민이 채집터·채소밭 등의 빈자리를 자동으로 채운다. 인력이 충분하면 균형·먹거리·건설의 식량 생산이 같을 수 있다. 방침의 이름이 추가 생산을 보장하지 않으며, 실제 예상 재고 변화와 공사량을 비교해야 한다. 이전 작업반 규칙에서 얻은 장기 주행 수치를 새 영지 규칙의 난이도 근거로 재사용하지 않는다.

물자 주문은 식량 주민 수의 2배(최대 200), 목재·석재 40, 도구 4, 장작 120 묶음이다. 실제 금액과 운송료를 주문 때 내고 기본 2주 뒤 받는다. 기본 수레는 3대이며 수레 차고가 있으면 4대·1주 운송으로 개선된다. 장터를 완공하면 물자 판매를 사용할 수 있다. 도착 전 물자는 건설 재료로 쓸 수 없다. 보좌관은 선임한 한 명이 실제 주 진행 때 한 번 활동한다. 교체·화면 열기는 즉시 효과를 주지 않고 같은 주에 중복 적용하지 않는다.

## 6 실제 조작 안내·결정·입력

부임 물자 화면에서 **실제 조작 튜토리얼**을 선택한다. 첫 학습은 다음 여섯 단계이며 실제 플레이 상태와 조작으로 진행한다. 설명을 넘기는 것만으로 시설을 완공하거나 결과를 확인한 것으로 처리하지 않는다.

| 단계 | 실제 행동 | 완료 확인 |
|---|---|---|
| 1 첫 특전 | 후보 중 하나 선택 | 첫 특전 결정 종료 |
| 2 개발 승인 | 농지 확대 승인 | 농지 예약·진행 공사 존재 |
| 3 주 진행 | 하단의 한 주 진행 실행 | 승인 이후 실제 완료 주 결과 생성 |
| 4 결과 확인 | 이번 주 탭의 결산 보기를 열어 읽고 닫기 | 상세 닫기 조작과 해당 주 결과 확인 |
| 5 완공 | 한 주씩 진행하여 농지 6구획 확보 | 실제 시설 수와 경과 주 확인 |
| 6 다음 운영 | 작업반 방침 선택 또는 다음 개발 목록 열기 | 해당 선택 조작 확인 |

처음 다섯 단계는 균형 배정을 유지하고 마지막 단계에서 작업반 비교를 연다. 목표 조작을 강조하며 현재 할 일 하나를 보여 준다. **안내 건너뛰기**는 회차를 그대로 둔 채 안내만 접는다. 도움말의 **멈춘 단계부터 따라하기**는 저장한 단계에서 재개한다. **실제 조작으로 다시 배우기**는 현재 상태를 읽어 재학습하며 이미 지은 농지나 보유 특전을 다시 얻도록 요구하지 않는다. 결과 확인과 마지막 선택은 실제로 수행해야 한다. 완료·건너뛰기 기록은 저장되며 학습을 완료한 사용자의 다음 준비에서는 안내가 기본 해제된다.

사건·특전·성물 후보는 배경 입력을 막는 중앙 모달에서 비교한다. 사건은 짧은 상황과 **비용 → 효과**, 특전은 효과와 보유 계열, 성물은 효과와 장착 조합을 보여 준다. EV01 안내는 실제 첫 개발로 대체하고 EV14 무비용 보상은 자동 소식으로 처리한다. 새 간편 회차에 추가 계절 계약 선택은 만들지 않는다.

**영지 상태 확인**이나 Esc로 미결 결정을 접어도 선택은 남는다. 진행 버튼은 **결정 먼저 확인**으로 바뀌며 F로 다시 연다. 선택 전에는 시간이 흐르지 않는다. 영지 사건을 결정하면 실제 지불·순변화와 확률 결과를 서신 결과로 보여 준다. 이 확인은 이미 반영된 결과를 읽는 단계이며 다시 지급하지 않는다.

계절 평가는 이미 적용된 보상 또는 미달 비용을 알리는 모달이다. 특전·사건이 함께 대기하면 그 선택이 먼저 나오므로 모달을 겹쳐서 조작하게 하지 않는다. 닫기나 저장 재개로 보상을 다시 지급하지 않는다. 52주 종료는 결산 화면에서 과업·시련·공훈과 다음 통치 준비를 연결한다.

| 입력 | 현재 동작 |
|---|---|
| Space | 통치 중 현재 계획으로 한 주 진행. 미결 결정이 있으면 먼저 확인 |
| F | 접어 둔 대기 결정 열기 |
| Esc | 상세 결과·계절 평가·기록 메뉴·도움말 닫기, 결정 접기 또는 상위 화면으로 이동 |
| 입력 칸 편집 / 모달 표시 | 배경의 시간 진행 단축키 차단 |

연속 자동 진행이나 숫자 메뉴 키를 기본 조작으로 요구하지 않는다. 제목·준비·강화·결산에서 Space로 진행 중인 회차의 시간이 흐르지 않는다.

## 7 도트 미술과 읽기 기준

새 타이틀 변경 전경 1장과 영주 출신별 도트 초상 3장, 정본 레귤러 12명의 도트 초상을 사용한다. 영주 후보용 그림은 출신 구분이며 모든 무작위 특성 조합의 고유 초상을 뜻하지 않는다. `title_frontier`, `lord_settler`, `lord_steward`, `lord_grower`의 생성 도구·전체 프롬프트·원본 경로는 `에셋 원본/generation_expedition.json`에 보존한다.

지형에 건물을 합쳐 그리지 않는다. 신작 집무실 1장, 계절 지형 3장(봄·여름 공용), 시설 시트 3장과 겨울 변형 시트 1장을 `godot/assets/frontier_v2/`에 저장했다. 시설 22종·임시 시설 3종·성소·공사장의 독립 텍스처 27종, 겨울 변형 9종을 nearest 필터로 합성한다. 별도 4지구 화면에서 지면과 발 위치를 맞추며, 클릭한 시설의 가동 정보·비용·조건은 고정 상세에서 확인한다. 현재 모든 시설에는 전용 그림이 있다. 자유로운 건물 배치는 구현하지 않았다. 긴 비용·사건 본문을 장면 위에 겹치지 않는다.

추가 판타지 세트는 `godot/assets/fantasy_v1/`의 계열 배경 6장과 시설 시트 2장, 총 PNG 8장이다. 전용 시설 18종을 독립 텍스처로 나누고 채택한 계열의 실제 완공 상태에 맞춰 이계 지구에 합성한다. 이전 기본 영지 원본 8장을 대체하거나 그 수량에 중복 포함하지 않는다.

성물 UI의 **독립 성물 아이콘 48개 + 지도 성소 1개 + 성소 내부 배경 1개**는 2026년 11월 18일 전용 도트 PNG로 생성하고 Godot 임포트를 완료했다. 성물은 `godot/assets/relics/F01~F16.png`, `C01~C16.png`, `G01~G16.png`, 이전 성소 원본은 `godot/assets/world/relic_shrine.png`이며 현재 지구에서는 `godot/assets/frontier_v2/building_relic_shrine.tres`를 사용한다. 성소 내부 배경은 `godot/assets/scenes/relic_shrine.png`다. 성물·지도 성소 49개는 투명 알파 PNG이고 배경은 불투명 PNG다. 에셋 목록·실제 파일·생성 기록 경로·임포트 결과가 연결된다.

내장 `image_gen.imagegen` 도구·전체 프롬프트·파일 경로·투명 배경 설정은 최초 14개 `godot/assets/relics/generation_prompts.json`, 추가 성물 12개 `generation_prompts_plus.json`, 운영 조합 성물 24개 `generation_prompts_builds.json`에 기록했다. 독립 PNG의 알파를 유지하고 배경에 미리 합치지 않는다.

일반 UI는 `SystemFont`의 맑은 고딕·Noto Sans CJK KR·sans-serif 대체 순서를 사용한다. 공통 라벨은 최소 18px, 본문·수치는 주로 18~22px이며 강조 수치와 제목은 더 크게 표시한다. 상단 주요 수치는 24px이며 보조 HUD만 14~18px를 사용한다. 제목 화면의 게임명은 별도의 큰 글꼴로 표시한다. 도트 글자는 특별 연출에만 제한하고 일반 설명·수치·선택지를 이미지 글자로 대체하지 않는다.

현재 창·카드·버튼은 `RealmTheme`의 얇은 픽셀 경계와 목재·철색·장부색을 사용한다. 이전 `ui_frame_paper` / `ui_frame_slate` / `ui_button_wax` 원본은 호환용으로 보존한다. 모든 행동을 같은 굵은 금테로 강조하지 않고 주 행동·선택·보조 행동의 대비를 구분한다. 코너와 테두리를 통째로 확대하지 않으며 읽기 면은 불투명하게 유지한다.

일반·주요·선택·마우스 올림·누름·비활성·키보드 포커스를 구분한다. 복잡한 그림은 배경에 두고 읽는 영역은 불투명하게 처리한다. 긴 화면은 해당 영역에서 스크롤하며 글자 전체를 작게 축소하지 않는다. 도트 테두리를 추가해도 내용과 행동의 구분, 실제 수치의 정확성은 별도로 검증한다.

## 9 코드 연결과 검증 범위

진입은 `ui/main.tscn → ui/main.gd → ui/realm_ui.gd`다. `realm_board.gd`가 4지구와 독립 시설·성소를, `realm_panels.gd`가 이번 주·공사·성장 패널을, `relic_screens.gd`가 성물 제안·획득·장착·발견 도감과 환경 표시를 배치한다. `realm_ui.gd`는 지도 선택·업무 메뉴·주 진행·실제 조작 안내·사건과 결과 모달을 연결한다. 주요 노드는 `OperatingWorkspace`, `DevelopmentProcess`, `PolicyChoices`, `WeekResult`, `NextWeek`, `TurnDetails`, `side_tab_overview/projects/growth`, `MapPlansToggle`, `RelicShrine`, `RelicOffer`, `RelicInventory`, `RunEnvironments`, `OpenCrisis`다. `crisis_screens.gd`는 부담 단계·위기 요구량·대비 경로·회차 결과를 표시한다.

현재 검사 개수와 최종 실행 결과는 최신 로그를 기준으로 확인하며 문서에 고정하지 않는다. 규칙 검사와 UI 조작·렌더 검사를 구분한다.

- 작업반 검사는 실제 방침별 생산·완공 차이, 20인 한도·농사 우선·재료 소비·벌목과 장작의 공유 인력, 예상 불변성·예상과 실제 경제 일치, 선택 실패 원복, 저장·재개와 지역별 52주 정책 비교를 확인한다.
- 안내 검사는 실제 특전·승인·주 진행·상세 닫기·완공·다음 선택으로만 진행하고 저장·건너뛰기·재개·재학습에서 자원이나 보상을 반복 적용하지 않는지 확인한다.
- 가문 강화·캠페인·주간 결과 검사는 가격·선행 조건·기한·성공과 실패·수지·예치금·도착·시련·보좌관·중복 지급·저장 복원·손상 거절을 확인한다. JSON 직전의 실제 상태도 검증한다.
- 환경 검사는 9조합과 준비 공개의 재현성, 조회·기본 보너스 불변성, 실제 생산·소비·교역 배율, 불량 스냅샷 거절, 저장 재개 뒤 같은 경제 결과를 확인한다. 9조합×3지역에 동일 정책을 적용해 환경 활성 전후 54회차를 비교하며 특정 승률을 맞추도록 상태를 조작하지 않는다.
- 성물 규칙 검사는 제안·비용·중복 획득·세 칸·교체·계열 조합·실제 조건 충족과 주간 중복 지급 방지·발견 기록을 확인한다. `test_village_relics_ui`는 실제 후보 선택·성소·보관함·교체·도감·환경 표시와 저장 재개를 조작한다. `run-tests.ps1 -Render`에는 성물 화면 렌더도 포함한다.
- 실제 메인 UI는 1280×720와 1440×900에서 집무실과 4지구, 세 탭, 건설 터 토글, 공사 우선순위와 실제 완공, 하나의 주 진행 버튼, 작업반과 결과, 사건·계절 평가와 안내 위치를 조작·렌더링으로 확인한다. 이전 화면의 검사 결과를 새 화면 검증으로 대신하지 않는다.
- 자동 주행의 출력은 선택한 정책의 결과다. 모든 전략의 난이도, 초보자의 이해도와 장기 재미는 별도 반복 플레이로 확인한다.

테스트 데이터·로그·화면은 실제 플레이 저장과 분리한 `godot/tests/output/`에 둔다. 새 화면이나 기능의 수를 완성도 검증으로 대신하지 않는다.

운영 조합은 `test_operating_builds.gd`의 실제 경제 비교·지불·저장·52주 주행과 `test_operating_builds_ui.gd`의 진행도·교체 예고·도감 필터·포인터 조작으로 검사한다. 확장 검사는 `test_content_plus.gd`의 실제 복합 특전·경제 소비처·유료 선택·후속 도착·저장 복원·무료 대안, `test_crisis_director.gd`의 단계·예고·판정·보상·기존 회차 격리, `test_relics_plus.gd`의 추가 성물과 비용 원자성, `test_plus_ui.gd`의 위기·성물·복합 특전 화면을 포함한다. 검사 개수와 최종 실행 상태는 최신 로그를 따르며 장기 재미 검증을 대신하지 않는다.

## 10 본편 확장 목표 · 현재 미구현

본편은 지역 지도·물류·정책·군사·연구·인물 장편 서사를 확장하되 기본 행동의 수와 보고 길이를 늘리지 않는다. 현재 자동화는 노동 배치와 보좌관 활동이다. 가격·재고 조건에 따른 자동 구매, 다지역 물류와 위임 예산은 후속 범위다. 새 기능도 기본 화면에는 결정할 일만 제시하고 세부 계산은 기록에 둔다.

접근성 확장 목표는 UI 배율과 패널 재배치, 색각 보조, 음악·효과음 개별 조절, 모션 줄이기, 텍스트 순간 표시, 키보드 포커스 순서와 읽기 도구 대응이다. 대비 목표는 일반 글자 4.5:1, 큰 글자 3:1이다. 현재 글꼴·버튼 포커스·입력 중 단축키 차단과 별도로 구현·실화면 검증해야 한다.

다음 수량은 **본편 제작 목표**이며 현재 보유 수량이 아니다. 전경 확장도 지형·독립 건물·상태 레이어를 따로 제작해 조합한다.

| 에셋 | 본편 목표 | 제작 규칙 |
|---|---:|---|
| 정착지 성장 상태 | 6단계×4계절=24 | 같은 시점의 모듈 조합으로 성장 비교 |
| 특화 레이어 | 농업·상업·공업·학술·군사 5 | 기본 전경 위 선택 조합 |
