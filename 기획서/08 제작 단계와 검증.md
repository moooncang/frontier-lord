# 제작 단계와 검증

현재 구현 기준은 11번 문서와 Godot 빌드 안내를 따른다. 아래 출시 로드맵과 장기 통치 실험은 제작 목표이며, 완료된 검증 결과가 아니다.

## 1 출시 범위와 제작 원칙

최종 출시물은 8개 시작 헌장, 3개 플레이 모드, 6개 독립 도전, 10단계 도전 규칙, 16권역과 48거점, 12역 핵심 인물, 480개 서사 노드와 모든 경제·정치 시스템을 포함한다. 첫 검증판의 적은 콘텐츠 수를 최종 게임의 규모로 간주하지 않는다.

대규모 콘텐츠를 먼저 복제하기보다 작은 범위에서 시간·경제·로그라이트·저장 구조를 함께 검증한다. 게임이 재미없을 때 콘텐츠 수량을 늘려 해결하려 하지 않는다. 반대로 일정이 부족하다고 필수 시스템을 서로 분리한 채 출시하지 않는다.

## 2 구현 전 결정 상태

| 결정 | 상태 | 남은 작업 |
|---|---|---|
| 기본 장르·턴·회차·영구 성장 | 확정된 설계 기준 | 프로토타입으로 재미 검증 |
| 자원·세금·생산·물류·정치 | 공식과 처리 순서 정의 | 수치 튜닝과 실측 |
| 전투·계승·로맨스 범위 | 정의됨 | 사례별 콘텐츠 작성 |
| 데이터·저장·연동 경계 | 정의됨 | 구현과 손상 테스트 |
| 상세 캐챗 정본 | 현재 미확인 | 별도 문서 확보 후 설정·이미지 대조 |
| 아트·음악 원본과 이용 범위 | 제작 전 | 에셋 명세와 권리 확인 |
| 공개 배포처·판매 가격 | 본 설계의 필수 입력 아님 | 배포 직전 결정 |

정본 대조는 인물 이름·과거·말투·이미지 매핑을 확정하는 조건이다. 이를 기다리는 동안 초상 대체재와 역할 ID로 경제·회차·저장 구현을 진행할 수 있다. 정본을 보지 못한 상태에서 최종 인물 CG나 모든 대사를 확정하지 않는다.

## 3 단계별 제작

| 단계 | 실제 산출물 | 합격 기준 |
|---|---|---|
| P0 규칙 검증 | 수치 표, 자동 52주 계산, 데이터 검증기, 정본 대조표 | 자원 보존·세수·급여·식량 예제 일치 |
| P1 첫 치세 단면 | 하사, 1권역 3거점, 12시설, 8기술, 2세력, 20사건, 6특전 | 1년을 처음부터 끝까지 플레이, 실패 원인 이해 |
| P2 반복 구조 | 3헌장, 4년 시험 회차, 가문 강화 8개, 18특전, 저장 결산 | 서로 다른 3회차가 다른 전략을 요구, 보상 중복 없음 |

P2의 4년 회차는 빠른 검증을 위한 내부 설정이다. 최종 기본 회차는 6~10년이다. P1 시설은 B01·B06·B13·B14·B17·B19·B22·B25·B27·B49·B59·B63이며 인구 단계·연구를 시험용으로 우회할 경우 내부 디버그 표시를 남긴다. 일반 출시 난이도에 우회를 숨기지 않는다.

## 4 의존성과 작업 순서

단위·저장·명령 검증이 먼저다. 다음은 인구·재고·노동·생산·소비·원장, 그다음 사업·물류·세금·위임, 이어서 사건·세력·인물, 마지막으로 외교·전쟁·계승·고급 콘텐츠를 연결한다. 회차 종료와 메타 저장은 경제 코어와 함께 일찍 구현한다. 출시 직전에 영구 성장을 덧붙이면 저장 구조를 다시 만들게 된다.

화면은 실제 시뮬레이션 상태를 읽는 최소 UI부터 만든다. 전경 연출과 고품질 초상은 주요 기능과 병행하되 시뮬레이션 API를 바꾸지 않는다. 수치 조정은 데이터 변경으로 끝나야 하며 UI 코드 안에서 숨은 값을 고치지 않는다.

## 5 밸런스 검증 실험

| 실험 | 조건 | 통과 기준 |
|---|---|---|
| 초회 생존 | M업그레이드 0, 기본 영주, 하사 100시드 | 안내대로 실행하면 첫 겨울 생존 95% 이상 |
| 순수 완주 | 영구 효과 전부 끔, 표준 100시드 | 숙련 전략 3종 모두 승리 경로 존재 |
| 시작 조건 | 모든 헌장×100시드 | 필수 자원·식량 대안·교역 경로 충족 100% |
| 특전 다양성 | 1,000회 제시 로그 | 무효 후보 0, 한 계열 편중 강제 없음 |
| 가문 강화 | 가문 특성 0·206·412·618공훈 예산, 공통 강화 별도 | 생산·비용 배율과 방침의 득실이 실제 원장과 일치, 중복 적용 없음 |
| 재정 | 인구 80·1,200·8,000 | 군 규모 1~2%에서 유지 가능한 정책 조합 존재 |
| 공급망 | 농업·수입·혼합 3전략 | 한 노선 실패에도 사전 대안 있으면 재난 회피 |
| 전쟁 | 전력비 0.5~2.0, 지형·보급 조합 | 정보와 손실 일관, 보급 우위가 유의미 |
| 장기 인구 | 40년, 이민 제한 포함 | 음수·과도한 즉시 성장·연령 유실 없음 |
| 소규모 치세 | 인구 500 이하 유지 | 정복·대도시 없이 과업 완주 가능 |

첫 겨울 생존 95%는 제작 목표다. 실제 실행으로 검증하기 전 달성했다고 표시하지 않는다. 무작위만으로 실패하는 나머지 5%를 허용한다는 뜻도 아니다. 안내 이해도와 조작 실수까지 포함한 플레이 실험에서 기준을 측정하고, 불가능한 생성 조합은 별도 오류로 제거한다.

## 6 필수 테스트와 불변식

핵심 테스트는 돈·식량·인구 보존, 예약 중복, 처리 순서, 저장 복구, 동일 시드 재현, 결산 중복 방지다. 설명 문장을 그대로 검증하는 무의미한 테스트를 대량 생성하지 않는다.

| 사례 | 기대 결과 |
|---|---|
| 두 사업이 같은 목재를 예약 | 합계가 재고 초과면 둘째 명령 거부 |
| 군대가 마을을 떠남 | 주민 또는 군 급양에서 한 번만 소비 |
| 같은 사건 창 재열기 | 효과 1회, 대사 재열람 가능 |
| 결산 직후 강제 종료 | 재접속 후 보상 0회 또는 1회, 2회 불가 |
| 금고 0에서 급여일 | 체불 계약 발생, 음수 현금 무한 확대 없음 |
| 창고보다 많은 수확 | 야적·부패 경보, 조용한 삭제 없음 |
| 예정 면담 전에 인물 사망 | 면담 취소·대체 기록, null 오류 없음 |
| 가신을 원정과 면담에 동시 배정 | 일정 충돌 사전 표시 |
| 연구 선수 순환 | 콘텐츠 빌드 실패, 해당 ID 보고 |
| 외부 저장 알 수 없는 효과 | 실행 거부, 원본 보존 |
| 캐챗으로 금화 증가 | 자유 모드 복사, 공훈 지급 불가 |
| 메타 업그레이드를 도중 구매 | 현재 회차 스냅숏 불변 |
| 특전 새로고침 후 불러오기 | 후보·남은 횟수 동일 |
| 수도 함락 후 봉신 잔존 | 합법적 재기 경로 또는 명시 결산 |
| 섭정 뒤 후계 성년 | 정해진 법과 승인으로 권한 전환 |
| 부두 없는 노선에서 강선 주문 | 발주 또는 출발 조건 오류 명시 |

## 7 사람이 검증할 재미

첫 20분에 생존 목표·다음 행동·상반된 선택 1개가 보여야 한다. 2시간 안에 자기 영지의 특화와 버린 기회가 생겨야 한다. 첫 실패 뒤 참가자가 원인 2개와 다음 시도의 다른 전략 1개를 설명할 수 있어야 한다. 회차 종료 뒤에는 새 해금 때문에 다시 해 보고 싶은 선택이 최소 1개 남아야 한다.

표준 회차 4~8시간을 넘는 원인이 미결 안건 반복인지 새 내용인지 분리해 측정한다. 13주 동안 같은 자원 수동 구매를 3회 이상 반복하면 위임 기능 부족이다. 인물 사건을 읽기 위해 일부러 경영을 망쳐야 하면 조건 설계 오류다. 로그라이트 보상 때문에 흉년을 기다리거나 고의 자살이 최적이면 보상표를 수정한다.

## 8 콘텐츠 제작 규격

노드 1개에는 진입 조건, 등장 인물, 본문, 선택 2~4개, 확정 결과, 후속 약속, 불가능 상태 대처, 연대기 문장, 재등장 규칙이 들어간다. 중요 사건은 담당 인물 부재·사망·다른 지역 체류에도 모순 없는 대체 경로가 있어야 한다.

대사 분량 계획은 인물 120노드×평균 1,200자, 지역 144×700자, 일반 120×350자, 외교 48×800자, 계승 24×1,000자, 위기 24×850자로 약 369,600자다. UI 문구·변형·아이템 설명은 별도다. 이는 집필 예산이며 현재 완성된 대본 분량이 아니다. 09번의 12개 사건은 데이터화할 수 있는 기준 샘플이다.

작업량 추정은 P2 완료 후 실제 시설 1종·사건 1개·인물 비트 1개의 제작·수정 시간을 측정해 산정한다. 검증 없는 출시 날짜를 확정하지 않는다. 아트 제작 전에 각 시설과 이벤트의 필요 장면을 에셋 목록에 연결한다.

## 10 출시 완료의 정의

플레이어가 각 헌장을 정상적으로 시작해 성공·실패·은퇴로 결산하고 다음 회차를 시작할 수 있어야 한다. 모든 공훈과 해금은 저장 복구 후 일치해야 한다. 장기 통치에서는 계승 뒤 계속 플레이할 수 있어야 한다. 시설·정책·특전의 효과가 화면 설명과 계산에 일치하고, 주요 인물의 비연애 결말도 완결되어야 한다.

모든 목표 수량을 파일 개수로만 맞추지 않는다. 각 시스템의 기능, 갈등, 조합, 플레이 경로가 실제로 구별되어야 한다. 그 기준을 통과해야 큰 볼륨이 완성된 것이다.
