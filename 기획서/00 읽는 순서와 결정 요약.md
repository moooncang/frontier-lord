# 변경의 신임 영주가 되었다 제작 전 기획서

기준일 2026년 11월 8일 · 게임 설계 v1.0 · 대상 프로젝트 변경의 신임 영주가 되었다

**매번 다른 조건으로 변경의 영주가 되어 영지를 경영하고, 치세를 마칠 때 얻은 유산으로 다음 도전의 특전과 가문 강화를 여는 영지 경영 로그라이트.** 한 회차는 완결된 치세이며, 여러 회차에 걸쳐 도시 운영, 지역 분업, 봉신 정치, 외교, 전쟁과 인물 서사의 다른 면을 발견한다. 규모가 커질수록 노동 배치보다 제도와 사람을 선택한다.

이 묶음은 기존 「영지물 운영 게임 기획 초안」을 바탕으로 구조를 다시 설계한 제작 기준이다. 기존 초안은 비교용으로 남긴다. Godot 1차 실행 코드는 별도 `godot/` 폴더에 있으며 현재 구현 범위와 실행법은 [빌드 안내](../godot/README.md)를 기준으로 한다. 2026-11-09 정본 인물 초상 12장·사계절 지형 4장·독립 시설 12종·아이콘 9종을 적용했다. 지형과 건물은 별도 노드로 합성하며 사건은 중앙 팝업으로 표시한다. 일반 UI는 가독성을 위해 한글 시스템 글꼴을 사용한다. 이 문서의 본편 규모와 밸런스 수치는 전체 제작 목표이며 플레이테스트로 확정할 값이다.

## 초안에서 크게 고친 부분

1. **인구 증가와 건물 해금만으로 후반을 채우지 않는다.** 물류망, 지방 대표, 산업 특화, 조약, 봉신의 자치, 계승으로 새 문제가 열린다.
2. **식량 주 수는 결과 표시값이다.** 실제 식량 재고와 운송, 부패, 수확, 배급을 계산한다. 멀리 있는 곡물은 곧바로 수도 주민을 먹이지 않는다.
3. **세수와 군 유지비를 같은 연간 규모로 맞춘다.** 초안의 병사 월 4금은 기본 급여에서 제외한다. 병사 연 8금 급여와 별도 장비·급양으로 변경한다.
4. **가신의 능력이 장부의 정확도를 바꾸지 않는다.** 장부는 언제나 정확하고, 행정관은 수금률·감사 속도·사업 조정을 개선한다.
5. **호감, 정치적 동의, 직무 수행을 분리한다.** 친한 가신도 법에 반대하며, 적대적인 전문가는 계약 아래 일을 잘할 수 있다.
6. **계절 안건 수를 제한한다.** 성장 후에도 대다수 주는 결단 0~2건, 최대 3건이다. 나머지는 위임 규칙으로 처리한다.
7. **고정 엔딩 없음과 성취감 부족을 분리한다.** 개척장·도시장·통치장·유산장을 완성하면 회고와 이어 하기 선택이 열린다.
8. **제작 단계를 잘라도 최종 게임 규모는 유지한다.** 첫 제작 검증판은 전체 구조를 작은 지역에서 검증하는 단계이며, 최종 출시 목표를 대신하지 않는다.
9. **치세를 반복 가능한 단위로 재구성한다.** 시작 조건, 지역, 영주 특성, 사건 묶음, 위기와 특전이 달라진다. 패배해도 유산을 남기며 회차 간 영구 성장과 회차 내 성장의 경계를 명확히 한다.

## 정본과 새 설정의 경계

초안에서 확인된 지명, 4세력, 캐챗 이미지 경로 체계는 계승한다. 2026-11-09 캐챗 정본(크랙 프로젝트 `claude/영지물 메인 프롬 초안` #12)과 대조해 핵심 인물 12인을 확정했다. 캐챗 등록 인물 12인이 그대로 게임의 핵심 인물이며, CH01~CH12와 캐챗 A~L의 대응·인물 디자인은 04번 2장이 기준이다.

이름·나이·외형·말투·성격은 캐챗 정본을 따른다. 인물의 실무·금지선·10비트 서사·직책 효과·새 지명은 **게임판 설계**다. 정본 초상 12장은 게임에 적용했다. 개별 생성 프롬프트와 원본은 에셋 원본/generation_canonical.json에 기록했다.

## 완성의 뜻

제작 전 완성은 모든 설계 선택이 시험 가능한 규칙으로 연결된 상태를 뜻한다. 재미, 실제 플레이 시간, 최적 난이도는 실행 가능한 게임과 플레이테스트를 거쳐 검증한다. 480개 서사 노드 등 콘텐츠 수량은 **출시 제작 목표**이며, 현재 전량 대본이나 에셋이 존재한다는 뜻이 아니다. 이 기획서는 전체 시스템, 콘텐츠 개별 기능과 범위, 집필 규격, 대표 완성 사건, 제작·검증 기준을 제공한다.
